> [!WARNING]
> **A quick heads-up:** 0.9.0-beta.1 is an installer-testing preview, not a stable release. The Windows Setup file is unsigned, so Windows SmartScreen may show a warning. If you’re here to try it, welcome—just keep that in mind before installing.

Your PC games should feel at home together. Luma brings them into one calm, controller-first space, with keyboard and pointer support close at hand too. Pick your platform below and give the preview a try.

## Choose a download

| Platform | Package | Download | Notes |

The `.nupkg` files attached to the release are updater packages; most people should use the download for their platform above. [Browse all releases](https://github.com/LordYamoshi/Luma-releases/releases).

## Install

### Windows

1. Download the setup installer or portable archive above.
2. Run the installer, or extract the portable archive.
3. Launch Luma.

The Setup installer in this preview is unsigned. Review the warning above before installing.

### Linux

1. Download `Luma.AppImage` above.
2. Make it executable, for example with `chmod +x Luma.AppImage`.
3. Open it to launch Luma. This preview requires `libfuse2`.

## About Luma

Luma brings your games into a game-first home designed for controller play, while staying comfortable to use with a keyboard and pointer too. The goal is simple: make your PC feel a little more like your own gaming system.

This repository hosts Luma installers and update packages. The application source is maintained separately.
