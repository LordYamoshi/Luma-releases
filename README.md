## Install

### Windows

1. Download the setup installer or portable archive above.
2. Run the installer, or extract the portable archive.
3. Launch Luma.

The setup installer in this preview is unsigned. Review the warning above before installing.

## About Luma

Luma brings a game-first Home, library, and system layer together in one controller-first environment. It is built for the games you already own and keeps keyboard and pointer support available alongside controller navigation.

This repository hosts Windows installers and update packages. The application source is maintained separately.
